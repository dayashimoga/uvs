# User Guide & Keyboard Shortcuts

Universal Video Studio is designed for rapid keyboard-driven and touch-first operation.

---

## 1. Global Keyboard Shortcuts

| Shortcut | Action | Scope |
| :--- | :--- | :--- |
| `Space` | Play / Pause | Player, Studio, Quick Edit |
| `Left Arrow` | Step 1 frame backwards | Player, Studio |
| `Right Arrow` | Step 1 frame forwards | Player, Studio |
| `S` | Split clip at current playhead | Studio Editor |
| `Delete` / `Backspace` | Ripple delete selected clip | Studio Editor |
| `I` | Mark In Point | Quick Edit, Studio |
| `O` | Mark Out Point | Quick Edit, Studio |
| `Ctrl + Z` / `Cmd + Z` | Undo last operation | Global |
| `Ctrl + Y` / `Cmd + Shift + Z` | Redo last operation | Global |
| `Ctrl + S` / `Cmd + S` | Atomic Project Save | Studio Editor |
| `F` | Toggle Fullscreen | Player Mode |

---

## 2. Mode Workflows

### 2.1 Player Mode
* Open media files using the file picker or drag & drop directly into the player window.
* Tap the gear/sliders icon to adjust audio delay if audio is ahead of or behind video.
* Use `Set A` and `Set B` to repeat an exercise, dialogue clip, or dance segment continuously.

### 2.2 Multi-View Mode
* Select layout from top dropdown (e.g. `2x2` for 4 angles).
* Unmute any combination of feeds simultaneously to mix sound from multiple sources.
* Click `Send to Multicam` to assemble all feeds into a synchronized editing timeline.

### 2.3 Quick Edit Mode
* Drag the left and right handles on the bottom range slider to trim video immediately.
* Choose target aspect ratio (`9:16` for TikTok/Reels, `1:1` for Instagram, `16:9` for YouTube).
* Pick a color look preset and click `Export Quick Video`.
